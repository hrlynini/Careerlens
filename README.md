 CareerLens

AI-Powered Career Readiness Assistant

CareerLens is an AI-powered platform that helps students and early-career engineers make smarter job application decisions. It analyzes resumes against job descriptions to determine job compatibility, identify skill gaps, and recommend practical projects and learning resources to improve career readiness.

Features

Analyze & Decide: Get an AI-powered resume compatibility score, evidence-backed strengths, skill gaps, and personalized upskilling recommendations.

AI Job Finder: Generate sample internship and entry-level job opportunities based on your technical skills.

Application Tracker: Save analyzed jobs, manage application statuses, and track progress.

Cross-Job Skill Gaps: Identify commonly requested skills across job descriptions and prioritize what to learn next.

Tech Stack

Frontend: React 19, Vite

Backend: Python, FastAPI

AI Integration: Google Gemini / Anthropic Claude

Validation: Pydantic

PDF Processing: pypdf

Storage: Browser localStorage
